# Anime Samani 1.1 / Guide / ガイド

[Français / English release notes](../../RELEASE-NOTES.md) · [日本語](../../RELEASE-NOTES.ja.md)

**FR :** Mise à jour depuis 1.0 : garde ton profil. Les favoris et fonds restent disponibles. Paramètres → Général regroupe les domaines, la recherche automatique, les publicités et le thème du site. La recherche propose une adresse ; clique pour l’appliquer. Les anciennes positions sont réduites aux 500 plus récentes. Les anciens fonds remplacés sont supprimés, pas les fichiers originaux.

**EN:** Upgrade from 1.0 using your existing profile. Favorites and your current background are retained. Settings → General contains domains, automatic discovery, ads and website theming. Discovery suggests an address; click to apply it. Saved playback history retains the newest 500 entries. Replaced background copies are removed, never your original files.

**日本語：** 1.0 のプロファイルを引き継ぎます。お気に入りと現在の背景は維持されます。設定 → 一般にドメイン、自動確認、広告、テーマの設定があります。候補をクリックしてアドレスを適用します。再生位置は最新500件を残します。置き換えた背景のコピーを削除しますが、元ファイルは削除しません。
