# Anime Samani 2.0

- Lively Wallpaper の動きを参考にした `DrillIn` 形式のパネル・設定タブ遷移。
- サイドバーアイコンにホバー・クリック動作を追加。動作の途中でページを切り替え、連続した遷移にしました。
- イントロと初期レイアウトが完了するまで画面遷移を無効化し、起動時のちらつきを抑制。
- メインボタンのグラデーション、控えめな反射、押下時の動きを改善。
- 元のデザインから高品質なアンチエイリアスでアプリ・Windows 用ロゴを再生成。
- Windows の「アニメーションを減らす」設定に対応。
- オリジンをまたぐリダイレクト時の認証情報漏えいを修正した `electron-updater` へ更新。
- ナビゲーションの連続クリック競合を防止し、エラー後もアニメーション状態を確実に解除。

1.x のお気に入り、再開履歴、カスタム背景、ドメイン、設定は保持されます。

検証：ESLint、Prettier、47件の回帰テスト、起動・ガイド・ナビゲーション・設定・ドメイン・お気に入り・再生・シネマモード・更新・ローカルメディア境界を確認する Electron テスト。
