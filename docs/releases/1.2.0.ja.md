# Anime Samani 1.2

- パネルと設定タブに新しい画面遷移を追加。
- サイドバーアイコンにホバー・クリック動作を追加。動作の途中でページを切り替えます。
- イントロと初期レイアウトが完了するまで画面遷移を無効化し、起動時のちらつきを抑制。
- メインボタンのグラデーションと押下時の動きを改善。
- 元のデザインを保ちながら、アプリ・Windows 用ロゴのアンチエイリアスを改善。
- Windows の「アニメーションを減らす」設定に対応。
- オリジンをまたぐリダイレクト時の認証情報漏えいを修正した `electron-updater` へ更新。
- ナビゲーションの連続クリック競合を防止し、エラー後もアニメーション状態を解除。
